A project is one conversation with the AI Marketer about one job, with its own context and results. Open **AI Marketer → Projects** in the sidebar.

## Start a project

<Steps>
  <Step title="Click New project">
    On the **Projects** page, click **New project**.
  </Step>
  <Step title="Name it and add context">
    Give it a **Name** (for example "Black Friday launch") and, if you like, **Context**: goals, budget, rules the agent should follow. The agent reads the context on every message in this project. Pick a **Cover** to tell projects apart at a glance.
  </Step>
  <Step title="Start empty or from a chat">
    Under **Start from a chat** you can pick an existing chat — its messages become the project chat. Leave it empty to start fresh.
  </Step>
  <Step title="Click Create project">
    The project opens with a first message from the agent asking what to do first.
  </Step>
</Steps>

You can also turn a chat into a project from the chat's menu: **Make this a project**.

## Inside a project

The project page is the project's chat, with a panel next to it:

- **Results** — the reports and creatives the agent made in this project. Ask the agent for a report, a deck or creatives and they land here.
- **Schedules** — recurring tasks that belong to the project. **New schedule** adds one. See [Scheduled tasks](/agent/schedules).
- **Context** — the goals and rules the agent reads on every message. **Edit** to change them.

From the project's menu you can **Rename** it, **Change cover** or **Delete project**. Deleting a project keeps its chat in your chat history; deleting the chat itself deletes its project and context, and that can't be undone.
