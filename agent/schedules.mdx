Set a task once and Ryze runs it on its own — either **repeating** (every day, week, or month) or **one-time** at a specific moment in the future. Each run does the work in a fresh chat and sends you the result by email or Slack, so the report is waiting for you instead of being something you have to go pull.

One-time tasks are great for reminders and one-off checks — "pull this report tomorrow at 9am", or "check spend after the sale ends Friday". After a one-time task runs, it's marked **Completed** and won't run again.

Find it under **Schedules** in the sidebar, in the **AI Marketer** group.

## Create a scheduled task

Click **Create with Agent** and just say what you want in chat. The agent briefly explains how scheduled tasks work, asks a few questions to nail down what to do and when it should run, then creates the schedule for you.

Prefer a starting point? Click **View templates** to open Templates on the **Automate** section, with ready-made automations you can build with the agent. See [Templates](/agent/templates).

The agent also suggests this on its own — ask a question you'll clearly want answered again next week and it offers a recurring task, or mention a specific moment ("check this after the sale ends Friday") and it offers a one-time task for that time. It offers once and creates the task only after you say yes. Before creating a recurring task, it tells you how many runs that means and that every run uses credits.

<Tip>
**Describe the task as one instruction to carry out now**, not as a routine. The cadence already lives in the schedule, so "Produce a concise paid-media report for yesterday, compared with the prior day and the same weekday last week" is clearer for the agent — and for anyone reading the task later — than "Every morning, produce a concise paid-media report…".
</Tip>

New tasks are **active as soon as they're created**. A workspace can hold up to 30 scheduled tasks; past that you'll see **Schedule limit reached (30 per workspace)**.

<Warning>
Runs are billed per AI step like any agent work (see [Credits & Usage](/agent/credits)), and the agent can use every tool it has access to — including changing or deleting things in your connected accounts. Write the task carefully and use at your own risk.
</Warning>

## What happens on each run

When a schedule fires, Ryze:

1. **Starts a fresh chat** and runs your task as the agent.
2. **Writes the result** — the agent does the work and ends with a short recap: the verdict and the key numbers.
3. **Sends the recap** to the task's recipients — by email, to Slack channels, or both — with a link to open the full chat.

The message is a short headline. The full reasoning and detail live in the chat behind the link.

<Note>
Scheduled-run chats are read-only — they're a record of what the agent did, not a conversation you continue. To change what runs, edit the task.
</Note>

**Replies to the result email don't reach the agent.** When a run finds a change that needs your sign-off — a budget, bid, targeting, keyword, creative or content change — it files an approval card instead of asking you in the email. Open **Home → Needs you** or the **Inbox** and click **Approve** or **Reject** there (see [Inbox and approvals](/agent/approvals)). To give the agent new instructions, start a new chat or edit the task.

## When a run is skipped

Some runs don't happen. The task's run history shows why:

- **Your plan is paused or its last payment didn't go through** — the run is skipped. A repeating task picks up on its own once the plan is active again; a one-time task won't run again on its own, so schedule it again then. If a payment failed, update your payment method in **Billing**.
- **No active subscription** — the run is skipped and the task is switched off.
- **Out of credits or the workspace's monthly credit cap reached** — the run is skipped and you get an email, **Your scheduled task was skipped** (at most once a month). Top up, or ask the organization owner to raise the cap on the **Usage** page, and the next runs go ahead.
- **The person who created the task left the workspace** — the task is switched off.

A run that hasn't finished after 24 hours is stopped and marked "Stopped: the run did not finish within its time budget."

## Manage a task

Use the **Search scheduled tasks** box to find a task. Open any task to see its instructions, schedule, next run, and recent runs.

- **Run now** — fire the task immediately. A task runs one copy at a time: while a run is still going, **Run now** says "This schedule is already running. Wait for the current run to finish before starting another." For a one-time task this is a one-off extra run — it doesn't use up the scheduled time, which still fires as planned. Once a one-time task is **Completed**, **Run now** is no longer available.
- **Toggle (Active / Paused)** — pause or resume a repeating schedule. Paused tasks don't run and don't bill. (One-time tasks show **Completed** once they've run.)
- **Refine with Agent** — opens a chat where the agent sums up the task and asks what you'd like to change — instructions, timing, or something else. It changes nothing until you answer.
- **Edit** — change the task yourself:
  - **Name** and **Task** — the instructions the agent runs each time. Write it like a prompt: what to check, what to report.
  - **When should this run?** — **On a repeating schedule** (every day, week, or month, at the time and timezone you choose) or **Once, at a specific time** (it must be in the future and runs exactly once).
  - **Recipients** — **Slack channels** and **Email recipients** that get the result of each run — up to 20 email addresses and 20 Slack channels per task. For a private Slack channel, invite @Ryze AI there first. **Also add recipients to this workspace** gives each email address a seat in the workspace, with access to everything in it.
- **Delete** — stops all future runs and removes the task's run history. This can't be undone.
