Every message you send in chat spends credits. The work the AI does — thinking, pulling data, generating creatives — is what you pay for.

## How a message is charged

Each reply starts at **1 credit**, then adds for the work it does:

| Action | Cost |
| --- | --- |
| **Base reply** — every message | 1 credit |
| **Each data action** — pulling spend, ROAS, editing a campaign, etc. | +0.33 credits |
| **Each ad creative generated** | +5 credits |

### Examples

- **"Hey agent!"** → no data pulled. **1 credit.**
- **"What's my Google Ads spend this week?"** → one data action. **1.33 credits.**
- **"Compare ROAS across my Meta and Google campaigns."** → pulls four reports. **2.32 credits** (1 base + 4 × 0.33).
- **"Generate 3 ad creatives for our spring launch."** → three creatives. **16 credits** (1 base + 3 × 5).

## Agent runs

Work the agent does on its own — [scheduled tasks](/agent/schedules) and the background research behind [Approvals](/agent/approvals) — is billed per run:

| Action | Cost |
| --- | --- |
| **Agent run** — one scheduled or background run | 3 credits |
| **Each data action during the run** | +0.33 credits |

Failed runs aren't charged, same as chat.

## See the cost of any reply

Hover the credit icon under any AI message to see exactly what it cost.

## What you're not charged for

You're only billed for work that lands:

- **Failed runs and errors** — if a reply hits an error, it doesn't cost credits.
- **Internal tool calls** — the housekeeping the agent does behind the scenes isn't charged; you pay for the data actions and creatives above, not the plumbing.
- **Chat on your own Anthropic key** — if you connect your own [Anthropic key](/integrations/anthropic), chat costs nothing in credits for the AI itself — only the tools it runs.

## Track your usage

Open **Organization Settings → Usage** to see consumption across your whole organization.

<Frame>
  <img src="/images/nav-organization-settings.png" alt="Opening Organization Settings" />
</Frame>

The Usage page shows:

- **Credit balance** — what you have left.
- **Spent this period** — used since your billing period started.
- **Credits by day** — daily consumption trend.
- **By workspace and by user** — who and what is spending.

## Running low? Top up

Buy credit packs anytime from **Billing**. Top-up credits **never expire** — they carry over until you use them.

| Pack | Price |
| --- | --- |
| 100 credits | $39 |
| 300 credits | $99 |
| 600 credits | $179 |

## Good to know

- A reply that pulls data or generates creatives does more work, so it costs more — hover the credit icon to see the breakdown.
- Credits never expire. Unused plan credits roll over — each billing period's allowance is added on top of your remaining balance, and top-up credits stay too.
- The Usage page breaks consumption down by workspace and by user, so you can see who's spending.
