## In this guide

- Asking for work in plain language
- Editing an article the agent just wrote
- Turning a one-off task into a schedule

## Where to find it

Open **AI Marketer → New chat** in the sidebar. Your earlier conversations are in **AI Marketer → Chat History**.

## Steps

1. Type what you want in the message box, in plain language — for example "Write an article about winter running shoes" or "Where am I overspending on Meta this month?".
2. Use the **+** button to attach files, pick images from **Media** or add reference ads.
3. Watch the agent work: it shows each tool it uses as it reads your data and makes changes.
4. Choose how much the agent may do without asking with the **Tool approvals** picker in the message box. The default is **Skip all approvals** — the agent runs every tool on its own. Switch to **Approve write & delete** (reads run freely, changes need your approval) or **Manual approve** (every tool that touches your data needs approval) to confirm changes first. See [Chat](/agent/chat#tool-approvals).
5. Ask for follow-ups in the same chat — a rewrite, a different angle, another creative.
6. Need the same task again next week? Ask the agent to put it on a schedule. It sets up a [scheduled task](/agent/schedules) for you.

Agent work is billed in credits per step. See [Credits](/agent/credits).
