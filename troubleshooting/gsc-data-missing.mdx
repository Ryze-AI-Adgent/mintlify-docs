---
title: "Google Search Console data missing"
description: "Why Search Console data is absent, incomplete, or looks wrong in Ryze, and how to fix it."
---

Search Console is the foundation of the SEO engine. When its data is missing, topic selection and prioritisation degrade noticeably.

## No properties appeared when connecting

The Google account you authorized has no Search Console access.

- Sign in with the account that owns or has access to the property
- Or have someone grant that account at least **Full** access in Search Console
- Personal versus work Google accounts is a frequent mix-up

## Data is missing for part of your site

Almost always the **property type**.

| property type | covers |
|---|---|
| **Domain** (`example.com`) | All subdomains, both protocols — recommended |
| **URL prefix** (`https://www.example.com/`) | Only that exact prefix |

A URL-prefix property for `https://www.example.com/` excludes `https://example.com/`, `http://`, and every subdomain. If half your traffic is missing, this is why.

Fix by verifying a Domain property and connecting that instead.

## Recent days are empty

Google reports with a **2–3 day delay**. The most recent days are always incomplete. This is Google's behaviour and cannot be accelerated.

Do not read the last 48 hours as a trend.

## A new property has almost no data

Search Console begins collecting when the property is verified. It does not backfill.

A property verified last week has a week of history, regardless of how long the site has existed. Nothing can recover the earlier period — but up to **16 months** accrues from verification onward.

## Numbers disagree with analytics

Expected. They measure different things:

- **Search Console** counts impressions and clicks from Google search results
- **Analytics** counts sessions after arrival, across all sources

They will never match, and reconciling them exactly is not a meaningful goal.

## The connection dropped

Google tokens can be revoked by password changes, security policy, or admin action in a Workspace organisation.

Click **Reconnect** on the card and re-authorize, then start a new chat.

## Data looks correct in Search Console but not in Ryze

1. Confirm the connection shows **Connected**, with no reconnect prompt
2. Confirm the correct property is selected for this workspace
3. Start a new chat — existing chats do not pick up connection changes
4. Allow time after connecting for the initial data pull

## Still stuck

Email [support@get-ryze.ai](mailto:support@get-ryze.ai) with the property URL and its type.
