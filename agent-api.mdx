---
title: "Ryze API for agents"
description: "Let your AI agent sign up for Ryze, get an API key, and call every Ryze tool over MCP or REST."
---

Your agent can create a Ryze account, get an API key and start working without you opening the app. You step in three times:

- read the code from the email
- click the link to connect an ad platform
- pay, when the agent sends you the payment link

## 1. Sign up

The agent sends your email and your website:

```bash
curl -X POST https://reports.get-ryze.ai/api/v1/agent/signup \
  -H "Content-Type: application/json" \
  -d '{ "email": "you@company.com", "domain": "company.com", "name": "My agent" }'
```

- Ryze emails an 8-digit code with the subject **"… is your Ryze code"**. It is valid for 1 hour. The email tells the user to share it only with their own agent.
- `domain` is the business website. Free email domains such as gmail.com are refused.
- `name` is optional and labels the key in your settings.

## 2. Verify

You give the agent the code. The agent sends it back:

```bash
curl -X POST https://reports.get-ryze.ai/api/v1/agent/verify \
  -H "Content-Type: application/json" \
  -d '{ "email": "you@company.com", "code": "12345678" }'
```

The response carries the key. It is shown once, so the agent should store it:

```json
{
  "api_key": "rk_live_...",
  "workspace_id": "...",
  "mcp_url": "https://connector.get-ryze.ai/mcp",
  "api_url": "https://reports.get-ryze.ai/api/v1",
  "docs_url": "https://help.get-ryze.ai/agent-api"
}
```

- A new email gets a new account with a workspace for the domain.
- An email that already has a Ryze account gets a key for the workspaces it can open. `workspace_id` is the one whose website matches `domain`, or `null` when there are several and none matches.
- Lost the response? Run signup and verify again. An existing account just gets another key, and old keys keep working until revoked.

## 3. Call tools

The key works the same way over MCP and REST. Both expose the same tools.

### MCP

Connect your MCP client to `https://connector.get-ryze.ai/mcp` with the header `Authorization: Bearer rk_live_...`.

### REST

List the tools with their descriptions and input schemas:

```bash
curl https://reports.get-ryze.ai/api/v1/tools \
  -H "Authorization: Bearer rk_live_..."
```

Call one by name. Arguments go inside `args`:

```bash
curl -X POST https://reports.get-ryze.ai/api/v1/tools/native__list_connections \
  -H "Authorization: Bearer rk_live_..." \
  -H "Content-Type: application/json" \
  -d '{ "args": {} }'
```

When the key covers several workspaces, pass `"workspace"` inside `args`. `native__get_workspaces` lists them.

## 4. Subscription

A new account has no subscription yet, so every tool except `native__get_workspaces` is refused with `subscription_required`. The `message` holds the payment link: send it to the user and retry after they pay.

## 5. Connect ad accounts

Connect a platform in 3 steps:

- call `native__create_connection_link` with the provider, for example `meta_ads`
- send the returned `url` to the user: one click opens the platform's sign-in, then they pick the accounts Ryze should use
- poll `native__list_connections` every ~30 seconds until the provider shows `connected: true`; its tools then appear in `GET /api/v1/tools`

The link works once and expires after 24 hours. It never signs anyone in to Ryze: whoever opens it can only connect a platform to that workspace.

Links work for Google Ads, Google Analytics, Search Console, Google Drive, Meta, LinkedIn, TikTok, Snapchat, Reddit, Pinterest, HubSpot, Slack and Zoho. Shopify, GitHub, Microsoft Ads and platforms that need an API key are connected in the Ryze app. If Slack or Google Drive is already connected, the link is refused so it never replaces a connection.

## Errors

A tool that ran but refused answers HTTP 200 with a `status`:

| `status` | Meaning |
|---|---|
| `invalid_arguments` | Wrong or missing arguments. `message` names the field. |
| `subscription_required` | No active plan. `message` holds the payment link. |
| `out_of_credits` | The plan's credits are used up. |
| `not_allowed` | The platform refused the action. |
| `not_found` | The object or the tool name does not exist. |
| `not_connected` | The platform is not connected. Use a connection link. |

```json
{ "status": "subscription_required", "message": "... https://reports.get-ryze.ai/pay/..." }
```

Problems with the request itself answer with an HTTP error and `{ "error": "..." }`:

| HTTP | When |
|---|---|
| 400 | Invalid signup or verify body, wrong code |
| 401 | Missing, invalid or revoked key |
| 403 | The key is valid but its user has no workspace |
| 429 | Rate limit reached |

## Limits

| What | Limit |
|---|---|
| Signups per email | 5 per hour |
| Signups per IP | 10 per hour |
| Verify attempts per email | 10 per hour |
| Requests per API key | 1,200 per hour |

## Manage keys

Your keys are listed in the app under **Settings → Profile → API keys**. **Revoke** deletes a key and stops it at once.
