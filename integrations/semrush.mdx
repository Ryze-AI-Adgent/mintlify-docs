---
title: "Connect Semrush"
description: "Connect your own Semrush API key so Ryze can pull domain and keyword analytics, backlinks, and referring-domain data."
---

Semrush connects with your **own API key**. Ryze uses it for domain and keyword analytics, backlinks, and referring-domain data via the Semrush Analytics API — and it runs on your own Semrush API-unit balance, not Ryze credits.

<Note>
This requires a **Semrush plan with API access**. Usage is billed against your own API-unit balance.
</Note>

## Step 1 — Find your API key

In Semrush, open the **Subscription info** page and go to the **API units** tab. Your API key is listed there, along with how many API units you have left.

<Frame>
  <img src="/images/semrush-account.png" alt="Reaching your Semrush account from the profile menu" />
</Frame>

<Warning>
Your API key gives access to your API-unit balance — don't share it publicly.
</Warning>

## Step 2 — Connect in Ryze

In **Workspace Settings → Integrations**, click **Connect** on the Semrush card, paste your key into the **API key** field, and click **Continue**.

## Troubleshooting

- **Key rejected** — confirm your Semrush plan includes API access and that you copied the full key from the **API units** tab.
- **Running out of units** — usage draws on your Semrush API-unit balance; the **API units** tab shows what's left.
