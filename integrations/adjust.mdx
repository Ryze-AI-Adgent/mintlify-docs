title: "Connect Adjust"
description: "Connect Adjust with your API token so the agent can report installs, events, revenue, cost, and cohorts by app, network, and campaign."
---

Adjust connects with your **API token**. Once connected, the agent can report mobile attribution: installs, events, revenue, cost, and cohorts by app, network, and campaign.

## Step 1 — Copy your API token

In Adjust, open **Account settings → My profile → API token** and copy it.

<Note>
If you sign in to Adjust with SSO, get the token from your Adjust account manager or support@adjust.com.
</Note>

## Step 2 — Connect in Ryze

On the **Integrations** page, click **Connect** on the **Adjust** card, paste the token into **API token**, and click **Continue**.

<Tip>
After connecting, start a **new chat** so the agent picks up the new integration.
</Tip>

## Troubleshooting

- **Token rejected** — copy the token again from **Account settings → My profile → API token**.

Still stuck? Email [support@get-ryze.ai](mailto:support@get-ryze.ai).
