BigCommerce connects with a **store-level API account**. Once connected, programmatic articles can publish to your BigCommerce blog, and the agent can work with products, categories, pages, redirects, and orders.

## Step 1 — Create an API account in BigCommerce

<Steps>
  <Step title="Create the API account">
    In BigCommerce, go to **Settings → Store-level API accounts → Create API account**.
  </Step>
  <Step title="Set the scopes">
    For publishing, set **Content — modify** and **Information & Settings — read-only**. Add **Products — modify** and **Orders — read-only** if the agent should edit product SEO and report revenue.
  </Step>
  <Step title="Copy the token and API path">
    After saving, copy the **access token** and the **API path** shown with it (it looks like `https://api.bigcommerce.com/stores/abc123xyz/v3/`).
  </Step>
</Steps>

## Step 2 — Connect in Ryze

On the **Integrations** page, click **Connect** on the **BigCommerce** card and fill in:

- **Store hash or API path** — paste the API path, or just the store hash from it (e.g. `abc123xyz`)
- **Access token**
- **WebDAV username (optional)** and **WebDAV password (optional)** — let Ryze set the featured image on each blog post. Find them in BigCommerce under **Settings → File access (WebDAV)**. Leave both empty to publish without post thumbnails.

Click **Continue**.

If articles already publish somewhere else, Ryze asks **Publish to BigCommerce?** Click **Publish to BigCommerce** to switch new articles there, or keep the current destination. You can change this any time in SEO settings.

<Tip>
The agent can use the new connection from your next message — no need to start a new chat.
</Tip>

## How publishing works

Each article is published as a BigCommerce blog post at your store's address plus `/blog/{slug}/`. Ryze sets:

- the author to **Editorial Team** and the publish date
- the meta description and the article's main keyword as meta keywords
- Article and breadcrumb structured data (JSON-LD) in the post body, so search engines see the title, author and dates

Republishing updates the same post and keeps the author and structured data.

## Troubleshooting

- **"Paste the API path or the store hash"** — the first field doesn't look like a store hash. Paste the full API path shown with your token.
- **"Enter both the WebDAV username and password, or leave both empty."** — fill in both WebDAV fields or neither.
- **"BigCommerce already has a blog post at "…" that Ryze did not create — rename the article slug or remove that post in Storefront → Blog."** — one of your own posts uses that address. Rename the article slug in Ryze, or remove that post.
- **"BigCommerce saved the post but could not give it the URL "…" — that path is taken by another page, product or redirect…"** — free that path in BigCommerce (or rename the article slug), delete the stray post in **Storefront → Blog**, then publish again.
- **Publishing fails or product edits are rejected** — the API account is missing a scope. Create a new API account with the scopes above and connect again.
- **"BigCommerce WebDAV rejected the username or password."** — copy both from **Settings → File access (WebDAV)** and paste them again. The WebDAV password is separate from your BigCommerce login.
- **"BigCommerce WebDAV is not reachable at … Try again."** — try again in a few minutes. If it keeps failing, check WebDAV access for this user under **Settings → File access (WebDAV)**, or leave both WebDAV fields empty to publish without thumbnails.
- **"The featured image could not be uploaded to BigCommerce over WebDAV, so the post has no thumbnail."** — the article is live without a cover image. Click **View** on the BigCommerce card and check **Post thumbnails**. The WebDAV username and password are entered when you connect, so if they're missing or wrong, connect BigCommerce again with the correct ones, then publish the article again.
