---
title: "Connect Duda"
description: "Connect your Duda website with API credentials so Ryze can publish blog posts and work with pages, SEO settings, and site-wide code."
---

Duda connects with **API credentials** — an account-level API username and password, not your Duda login. Once connected, the agent can work with pages, blog posts, SEO settings, and site-wide code on your Duda site, and programmatic articles can publish to your Duda blog.

## Step 1 — Get your API credentials in Duda

In Duda, open **Settings → API Access** and copy the **API username** and **API password**. API access is available only on Duda plans that include it.

<Note>
These are account-level credentials. The API only reaches sites inside this Duda account.
</Note>

## Step 2 — Connect in Ryze

On the **Integrations** page, click **Connect** on the **Duda** card and fill in:

- **API username**
- **API password**

Click **Continue**. Then choose the **Site** — the Duda site the agent edits and publishes to — and click **Save**. If the account has only one site, Ryze picks it for you.

If articles already publish somewhere else, Ryze asks **Publish to Duda?** Click **Publish to Duda** to switch new articles to Duda, or keep the current destination. You can change this any time in SEO settings.

<Tip>
After connecting, start a **new chat** so the agent picks up the new integration.
</Tip>

## Troubleshooting

- **Credentials rejected** — check that you copied the API username and password from **Settings → API Access**, not your Duda login.
- **The site you want isn't listed** — it belongs to a different Duda account. Use API credentials from the account that owns the site.
- **Card shows Require setup** — the Site wasn't saved. Click **View**, choose the Site, and click **Save**.
