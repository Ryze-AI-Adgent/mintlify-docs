title: "Connect CallRail"
description: "Connect CallRail with an API key so the agent can read calls, transcripts, call summaries, and tracking numbers, and tag or qualify calls."
---

CallRail connects with an **API key**. Once connected, the agent can read calls, transcripts, call summaries, and tracking numbers from your CallRail account — and make changes when you ask.

## Step 1 — Create an API key

In CallRail, open **Settings → Integrations → API Keys** and create or copy a key.

<Note>
The key sees exactly what your CallRail user sees. Transcripts and call summaries require Conversation Intelligence on your CallRail plan.
</Note>

## Step 2 — Connect in Ryze

On the **Integrations** page, click **Connect** on the **CallRail** card, paste the key into **API key**, and click **Continue**.

Then choose the **Account** the agent reads calls from and click **Save**. If the key has access to only one account, Ryze picks it for you.

## What the agent can do

- **Read** — calls (with transcripts, summaries and sentiment when your plan includes Conversation Intelligence), companies, trackers, form submissions, tags and users
- **Change** — tag or qualify calls, add notes, and create tags when you ask
- **Delete** — delete tags when you explicitly ask

By default the agent runs its tools on its own: the [**Tool approvals**](/agent/chat#tool-approvals) setting in the chat composer starts on **Skip all approvals**. To review changes before they happen, switch it to **Approve write & delete** (reads run freely, changes need approval) or **Manual approve** (every tool that touches your data needs approval). Scheduled tasks run without an approval step.

## Troubleshooting

- **"This CallRail key has no accounts."** — the user the key belongs to has no CallRail account access. Create the key from a user that does.
- **No transcripts or summaries** — Conversation Intelligence isn't on your CallRail plan.
- **Card shows Require setup** — the Account wasn't saved. Click **View**, choose it, and click **Save**.
