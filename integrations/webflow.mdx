Webflow connects with a **site API token** — a token you generate in your site's settings that lets Ryze write to your CMS without sharing your login. Once connected, programmatic articles publish straight into the Webflow collection you choose, with fields mapped automatically.

## Step 1 — Generate a site token in Webflow

<Steps>
  <Step title="Open Site settings">
    In the Webflow Designer, open the site menu (top left) and click **Site settings**. You can also reach settings from the Webflow dashboard.
    <Frame><img src="/images/webflow-site-settings.png" alt="Opening Site settings from the Webflow Designer menu" /></Frame>
  </Step>
  <Step title="Go to Apps & Integrations">
    In the settings sidebar, open **Apps & Integrations**.
    <Frame><img src="/images/webflow-apps-integrations.png" alt="The Apps & Integrations item in Webflow site settings" /></Frame>
  </Step>
  <Step title="Generate an API token">
    Scroll to **API access** and click **Generate API token**. Name it something recognizable, like `Ryze AI`.
    <Frame><img src="/images/webflow-generate-token.png" alt="The Generate API token button under API access" /></Frame>
  </Step>
  <Step title="Set the permissions">
    Ryze needs two scopes — everything else can stay on **No access**:

    | Permission | Access |
    |------------|--------|
    | **CMS** | Read and write |
    | **Sites** | Read-only |

    CMS is how articles are created and published, and Sites lets Ryze list your sites so you can pick one. Optionally, also set **Pages** to Read and write if you want the agent to fix page-level SEO (titles, meta descriptions) on your static pages.
  </Step>
  <Step title="Copy the token">
    Click **Create token** and copy it right away.
  </Step>
</Steps>

<Warning>
Webflow shows the token **only once**. If you lose it, revoke it and generate a new one.
</Warning>

## Step 2 — Connect in Ryze

On the **Integrations** page, click **Connect** on the Webflow card and paste your site token.

<Frame><img src="/images/webflow-connect.png" alt="The Connect Webflow dialog with the site token field" /></Frame>

## Step 3 — Choose the site and collection

After the token is verified, pick the **site** that hosts your blog and the **CMS collection** where generated articles should be published.

<Frame><img src="/images/webflow-choose-collection.png" alt="Choosing the Webflow site and CMS collection" /></Frame>

Ryze maps your collection's fields automatically — title, slug, body, and the featured image land in the right places without manual field mapping.


<Note>
**Collections with extra required fields.** Ryze fills title, slug, body, excerpt, date, and the featured image. If your collection has *other* required fields (for example a `tag` or `category` field), Ryze fills them automatically with a value it finds on your existing items — a valid option, reference, plain text, or date. If a required field has no usable value to copy (or is an image, file, or multi-reference), Ryze tells you exactly which field to make optional or give a default, at setup time, instead of failing on every publish.
</Note>


## Troubleshooting

- **Token rejected** — make sure it's a **site token** from that site's settings, not a workspace token, and that the CMS scope is set to Read and write.
- **Collection missing from the list** — the token only sees the site it was created on; generate the token on the site that hosts your blog.
- **"This Webflow token can read your site but not write to it — publishing would fail."** — shown when you save the collection with a token that has no CMS write access. Generate a new token with **CMS** set to Read and write (and **Pages** Read and write if you want page-level SEO fixes), then connect again.
- **The agent can't change a page's title or meta description** — the token has no **Pages** access. Generate a token with **Pages** set to Read and write and connect again.
