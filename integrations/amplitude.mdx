---
title: "Connect Amplitude"
description: "Connect an Amplitude project with its API key and secret key so the agent can query events, funnels, retention, cohorts, and saved charts."
---

Amplitude connects with your project's **API key** and **secret key**. Once connected, the agent can query event segmentation, funnels, retention, user activity, cohorts, and saved charts for that project.

## Step 1 — Copy your project keys

In Amplitude, open **Settings → Projects →** your project **→ General** and copy the **API key** and **secret key**. Both keys belong to one project — the key pair decides which project Ryze connects to.

## Step 2 — Connect in Ryze

On the **Integrations** page, click **Connect** on the **Amplitude** card and fill in:

- **API key**
- **Secret key**
- **Data residency** — `us`, or `eu` for projects hosted in the EU data center

Click **Continue**.

<Tip>
After connecting, start a **new chat** so the agent picks up the new integration.
</Tip>

## Troubleshooting

- **Keys rejected** — make sure both keys come from the same project and **Data residency** matches where it's hosted.
- **Wrong project** — the keys decide the project. Disconnect in **View** and connect again with the other project's keys.
