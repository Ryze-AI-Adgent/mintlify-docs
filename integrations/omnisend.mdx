Omnisend connects with an **API key**. Once connected, the agent can work with your email and SMS campaigns, automations, segments, contacts, and reports.

## Step 1 — Create an API key

In Omnisend, go to **Store settings → Integrations & API → API keys → Create API key**, and copy the key.

## Step 2 — Connect in Ryze

On the **Integrations** page, click **Connect** on the **Omnisend** card, paste the key into **API key**, and click **Continue**.

## What the agent can do

- **Read** — campaigns, automations, segments and their statistics, contacts, and products
- **Change** — add or update contacts and tags, create a campaign draft and send it, and pull performance reports when you ask
- **Delete** — delete products, segments, campaigns or contact tags when you explicitly ask. Contacts themselves can't be deleted.

By default the agent runs its tools on its own: the [**Tool approvals**](/agent/chat#tool-approvals) setting in the chat composer starts on **Skip all approvals**. To review changes before they happen, switch it to **Approve write & delete** (reads run freely, changes need approval) or **Manual approve** (every tool that touches your data needs approval). Scheduled tasks run without an approval step.

<Note>
Omnisend allows **55 performance report requests per day**. Reports count as changes in Ryze, so with **Approve write & delete** on you're also asked to approve report requests.
</Note>

## Troubleshooting

- **Key rejected** — copy the full key again, or create a new one in **API keys** and connect again.
