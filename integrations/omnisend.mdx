title: "Connect Omnisend"
description: "Connect Omnisend with an API key so the agent can work with email and SMS campaigns, automations, segments, contacts, and reports."
---

Omnisend connects with an **API key**. Once connected, the agent can work with your email and SMS campaigns, automations, segments, contacts, and reports.

## Step 1 — Create an API key

In Omnisend, go to **Store settings → Integrations & API → API keys → Create API key**, and copy the key.

## Step 2 — Connect in Ryze

On the **Integrations** page, click **Connect** on the **Omnisend** card, paste the key into **API key**, and click **Continue**.

<Tip>
After connecting, start a **new chat** so the agent picks up the new integration.
</Tip>

## Troubleshooting

- **Key rejected** — copy the full key again, or create a new one in **API keys** and connect again.

Still stuck? Email [support@get-ryze.ai](mailto:support@get-ryze.ai).
