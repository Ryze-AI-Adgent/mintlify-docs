---
title: "Connect Framer"
description: "Connect Framer using a project URL and API key."
---

Framer connects with two things: your **project URL** and an **API key** you generate in Framer.

## Step 1 — Create an API key in Framer

<Steps>
  <Step title="Open your project">
    Open your project in Framer.
    <Frame><img src="/images/framer-step-1.png" alt="Open your project in Framer" /></Frame>
  </Step>
  <Step title="Open project settings">
    Click the settings icon in the top-right corner to open project settings.
    <Frame><img src="/images/framer-step-2.png" alt="Open project settings" /></Frame>
  </Step>
  <Step title="Go to General settings">
    In General settings, scroll down to the end.
    <Frame><img src="/images/framer-step-3.png" alt="Scroll to the end of General settings" /></Frame>
  </Step>
  <Step title="Create and copy the API token">
    Create an API token and copy it. You'll paste it into Ryze next.
  </Step>
</Steps>

## Step 2 — Connect in Ryze

In **Workspace Settings → Integrations**, click **Connect** on the Framer card and fill in:

- **Project URL** — e.g. `https://framer.com/projects/...`
- **API key** — the token you copied from Framer

<Frame>
  <img src="/images/framer-connect.png" alt="The Connect Framer dialog in Ryze" />
</Frame>

Click **Continue**. You're connected.
