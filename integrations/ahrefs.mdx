---
title: "Connect Ahrefs"
description: "Connect your own Ahrefs API key so Ryze can pull backlinks, referring domains, domain rating, and organic keyword data."
---

Ahrefs connects with your **own API key**. Ryze uses it for backlinks, referring domains, domain rating, and organic keyword data via the Ahrefs API v3 — and it runs on your own Ahrefs API unit balance, not Ryze credits.

<Note>
This requires an **Ahrefs API subscription**. Only workspace owners and admins can create API keys, and each key is valid for one year.
</Note>

## Step 1 — Generate an API key

<Steps>
  <Step title="Open API keys">
    In Ahrefs, go to **Account settings → API keys**.
    <Frame><img src="/images/ahrefs-api-keys.png" alt="The API keys page in Ahrefs account settings" /></Frame>
  </Step>
  <Step title="Generate the key">
    Click **Generate API key**, give it a name like `Ryze`, and copy the key.
  </Step>
</Steps>

## Step 2 — Connect in Ryze

In **Workspace Settings → Integrations**, click **Connect** on the Ahrefs card, paste your key into the **API key** field, and click **Continue**.

## Troubleshooting

- **Key rejected** — confirm your Ahrefs plan includes API access and that you copied the full key.
- **Can't create a key** — only workspace owners and admins can; ask an admin on your Ahrefs account.
- **Running out of units** — usage draws on your Ahrefs API unit balance. Manage limits per key under **Account settings → Limits & usage**.

Still stuck? Email [support@get-ryze.ai](mailto:support@get-ryze.ai).
