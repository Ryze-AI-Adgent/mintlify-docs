<AccordionGroup>

<Accordion title="How do I add a second account for the same platform?">
Open the platform's card in **Workspace Settings → Integrations**, click **View**, then **+ Add account** and authorize the other login. Both accounts stay connected in the same workspace. See [Connect multiple accounts](/integrations/multiple-accounts).
</Accordion>

<Accordion title="Which account does Claude use by default?">
The **primary** account. Click the **star** next to an account to make it the primary. To use a different one, just ask Claude — for example, "show my other Google Ads account" — and it will use that account for the request.
</Accordion>

<Accordion title="How do I set the primary account?">
In the platform's dialog, click the **star** next to an account. A filled star marks the primary; an empty star means it isn't primary yet. Setting a new primary only changes Claude's default — nothing gets disconnected.
</Accordion>

<Accordion title="I manage many accounts. How should I set this up?">
Connect the accounts you need on each platform and set a primary. If you manage a large number and want help structuring workspaces, email [support@get-ryze.ai](mailto:support@get-ryze.ai).
</Accordion>

<Accordion title="An account shows as disconnected even though it's active.">
Click **Reconnect** on the platform card in **Workspace Settings → Integrations**, then start a new chat in Claude.
</Accordion>

<Accordion title="I connected GSC and GA4 — is there anything else to do?">
Connect whichever platforms you want Claude to read. Nothing else is required — just start a new chat after connecting.
</Accordion>

<Accordion title="How do I connect Shopify?">
Shopify needs a manual setup step. Email [support@get-ryze.ai](mailto:support@get-ryze.ai) and tell us which store domain you want connected.
</Accordion>

</AccordionGroup>
