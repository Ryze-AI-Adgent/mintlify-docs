---
title: "Connect ClickUp"
description: "Connect ClickUp with a personal API token so the agent can work with tasks, lists, spaces, comments, and docs in your Workspace."
---

ClickUp connects with a **personal API token**. Once connected, the agent can read and edit tasks, lists, spaces, comments, and docs in your ClickUp Workspace.

<Note>
The agent acts as you: it sees and edits what you can.
</Note>

## Step 1 — Generate a token

In ClickUp, go to **Settings → Apps → API Token → Generate**, and copy the token (it starts with `pk_`).

## Step 2 — Connect in Ryze

On the **Integrations** page, click **Connect** on the **ClickUp** card, paste the token into **Personal API token**, and click **Continue**.

Then choose the **Workspace** the agent reads and writes, and click **Save**. If you belong to only one Workspace, Ryze picks it for you.

<Tip>
After connecting, start a **new chat** so the agent picks up the new integration.
</Tip>

## Troubleshooting

- **"Personal API tokens start with pk_"** — copy the full token from **Settings → Apps**.
- **Card shows Require setup** — the Workspace wasn't saved. Click **View**, choose it, and click **Save**.
