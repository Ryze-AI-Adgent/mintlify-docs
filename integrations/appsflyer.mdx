---
title: "Connect AppsFlyer"
description: "Connect AppsFlyer with a Pull API token so Ryze can read mobile attribution — installs, in-app events, and aggregate metrics."
---

AppsFlyer connects with an **API token V2.0** (the Pull API token). Once connected, the agent can pull installs, in-app events, and aggregate attribution metrics for your app and combine them with your ad platforms in one answer.

## Step 1 — Get your Pull API token

<Steps>
  <Step title="Open the API tokens page">
    In AppsFlyer, open the account menu (your email) and go to **Security center → AppsFlyer API tokens → Manage your AppsFlyer API tokens**. Only an account admin can copy tokens here.
  </Step>
  <Step title="Copy the API token V2.0">
    Copy the **API token V2.0**. AppsFlyer revoked all V2 tokens generated before March 10, 2026 — if yours is older, regenerate it first.
  </Step>
  <Step title="Note your App ID">
    You'll also need the app identifier: the Android package name (e.g. `com.company.app`) or the iOS id as it appears in AppsFlyer (e.g. `id123456789`).
  </Step>
</Steps>

## Step 2 — Connect in Ryze

On the **Integrations** page, click **Connect** on the **AppsFlyer** card and fill in:

- **API token V2.0** — the token you copied
- **App ID** — the package name or iOS id; this becomes the default app for reports

Click **Continue**. The card shows **Connected** — click **View** to see the App ID you entered.

## Limits

The Pull API only serves roughly the **last 90 days**, and AppsFlyer rate-limits raw-data reports to a small number of calls per day per app. Ask for a date range once and reuse the answer rather than re-pulling the same days.

## Troubleshooting

- **"AppsFlyer rejected the API token."** — make sure it's the current **API token V2.0** copied by an admin, not a legacy V1 token or a V2 token generated before March 10, 2026. If the token is current, check in AppsFlyer that the account is not suspended.
- **"AppsFlyer has no app with this ID for this token."** — use the iOS id as it appears in AppsFlyer (starts with `id`, e.g. `id123456789`) or the Android package name, and make sure the token comes from the account that owns the app.
- **"AppsFlyer allows one check per minute for this app. Wait a minute and try again."** — wait a minute, then click **Continue** again.
- **Wrong app in reports** — the App ID you entered is the default. To add a second app, click **View** on the AppsFlyer card, then **Add one more account**, and connect with the other App ID.
