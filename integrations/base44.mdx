Ryze publishes to Base44 through Base44's own API. You give Ryze the link to your app and a Base44 access token. Ryze saves each article as a file in the app and publishes the app. The access token is stored encrypted.

<Warning>
**Publishing deploys the whole app.** Any changes you made in Base44 but haven't published yet go live with the next article.
</Warning>

## Before you connect

- **A published app.** Publish the app once in Base44 so it has a public address.
- **A Base44 plan that can publish apps.**
- **Base44 message credits** for the one setup prompt. Publishing, republishing and unpublishing don't use credits. See [Credits](#credits).

## Step 1 — Create an access token in Base44

<Steps>
  <Step title="Open Secrets">
    In Base44, click your workspace name at the bottom left, then **Settings**, then **Secrets**.
  </Step>
  <Step title="Create the token">
    Open the **Personal access tokens** tab and click **Create access token**. Give it a name, for example "Ryze".
  </Step>
  <Step title="Choose access and permission">
    Under **Access**, pick the app you want Ryze to publish to (or all apps). Under **Permission**, pick **Full access**. A read-only token can't save articles.
  </Step>
  <Step title="Copy the token">
    Click **Create access token** and copy the value. Base44 shows it only once.
  </Step>
</Steps>

Create the token in the workspace that owns the app.

## Step 2 — Connect in Ryze

<Steps>
  <Step title="Copy the app link">
    Open the app in the Base44 editor and copy the link from the browser address bar. It looks like `https://app.base44.com/apps/…/editor/preview`.
  </Step>
  <Step title="Open Integrations">
    On the **Integrations** page, click **Connect** on the Base44 card.
  </Step>
  <Step title="Fill in the fields">
    - **App link** — the link you copied
    - **Access token** — the token you created in Base44
  </Step>
  <Step title="Click Connect">
    The dialog shows **Base44 is setting up your blog** while Base44's AI works. This usually takes 1–2 minutes. Keep the window open.
  </Step>
</Steps>

### What the setup prompt does

During connect, Ryze sends Base44's AI one prompt that sets up the blog:

- Articles become JSON files in `src/content/articles/`, one file per article.
- `/blogs` lists every article, newest first, and `/blogs/{slug}.html` shows one article.
- A build step writes every article as a ready HTML page with its title, meta description, canonical link and body, so search engines can read it without running JavaScript.
- The same build step writes `sitemap.xml` (your public pages and every article) and `robots.txt`. They replace the ones Base44 generates.
- If your app already has a blog, Base44 rewires that blog to read these files and keeps its design. Otherwise it adds a **Blog** link to the main navigation.

The prompt asks Base44 not to change anything else and not to install new packages.

A reconnect skips the prompt when the blog is already set up. If you have used the app's chat in Base44 since the setup, a reconnect sends the prompt again.

## Article URLs

Articles live at `https://{your-app}.base44.app/blogs/{slug}.html`.

The `.html` ending is on purpose. Base44 hosting serves a prerendered page only at an address with a file extension. At an address without one, search engines get the app's generic page instead of the article. Visitors who open `/blogs/{slug}` without `.html` still see the article, but the `.html` address is the one Ryze uses in links, the canonical tag and the sitemap.

Ryze builds these addresses from your app's `base44.app` address.

## How publishing works

For each article Ryze:

1. Saves the article file straight into the app. No prompt is sent and no credits are spent.
2. Publishes the app. Base44 runs the build, which also writes the HTML pages and the sitemap.
3. Opens the article on your live site and checks its title and text. This check waits up to 1 minute.

One article usually takes about half a minute. Articles for the same app publish one at a time.

## Credits

| Action | Prompts | Base44 message credits in our tests |
| --- | --- | --- |
| First connect (setup) | 1 | about 3 |
| Reconnect when the blog is already set up | 0 | none |
| Reconnect after you used the app's chat | 1 | about 1.5–3 |
| Publish or republish an article | 0 | none |
| Unpublish an article | 0 | none |

These are approximate. Base44 decides the cost of each prompt.

## When Base44 is busy with your own prompt

Before it saves a file, Ryze checks whether Base44's AI is working on one of your prompts. If it is, Ryze leaves the app alone:

- **Scheduled publishing** retries on its own a few times. If Base44 is still busy after that, the article shows as failed and goes out with the next scheduled run.
- **Publish, Republish or Unpublish from the article page** stops with "Base44 is working on one of your prompts right now. Try again in a few minutes."

## Republish and unpublish

- **Republish** saves the new article file in place, at the same address. The article's date becomes the republish date, so it moves to the top of the blog list.
- **Unpublish** deletes the article file, publishes the app, and waits until the page is gone from your live site. No prompt is sent.

## Troubleshooting

| Message | What to do |
| --- | --- |
| Enter the app link from the Base44 editor | Copy the link from the Base44 editor's address bar (`https://app.base44.com/apps/…/editor/preview`), not your live site's address. |
| Base44 rejected this access token | Create a new access token with **Full access** and connect again. |
| This Base44 access token is read-only | Create an access token with the **Full access** permission and connect again. |
| Base44 refused this access token for that app | Give the token access to this app (or to all apps) with **Full access**, check the app link, and connect again. |
| Base44 found no app at this link for this access token | Copy the link from the app's editor and create the token in the workspace that owns the app. |
| This Base44 app has no public address yet | Publish the app once in Base44, then connect again. |
| Could not reach Base44 | Try again in a few minutes. |
| Base44 refused this request for the app's workspace plan or credits | Check the plan and the credits of the Base44 workspace, then try again. The message includes Base44's reason. |
| Base44 is out of message credits for this account | Add credits, or wait for the monthly credits in Base44, then connect again. |
| Base44 did not finish setting up the blog in time | Open the app in Base44, wait until its AI stops working, then connect again. |
| Base44's AI could not finish setting up the blog | Open the app's chat in Base44 to see what went wrong, then connect again. |
| Base44's AI stopped to ask for your approval | Open the app's chat in Base44, answer it, then connect again. |
| Ryze could not confirm that Base44 received the blog setup prompt | Check the app's chat in Base44, then connect again. |
| Base44 is working on one of your prompts right now | Let your prompt finish, then try again. Scheduled publishing retries on its own. |
| This Base44 app protects its main branch | Turn off main branch protection for the app in Base44, then try again. |
| Base44 is still finishing an earlier publish of this app | Try again in a few minutes. Scheduled publishing retries on its own. |
| Not enough time was left to publish the Base44 app | Try again in a few minutes. Scheduled publishing retries on its own. |
| Base44 could not publish this app right now | Try again in a few minutes. The message includes Base44's reason. |
| Base44 did not let this access token publish the app | Check that your Base44 account may publish this app and that the plan allows publishing. |
| Base44 refused to publish this app | The message includes Base44's reason. Fix it in Base44, then publish the article again. |
| The published site does not show the article yet | Try again in a few minutes. Scheduled publishing retries on its own. |
| The published site still shows the article after it was removed | Wait a few minutes and check the page again, then unpublish again if it is still there. |
| Another publish for this project is still running | Wait a few minutes for it to finish. |
