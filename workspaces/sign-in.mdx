Ryze signs you in with your email address. There is no Google sign-in button — always use the email you signed up with.

## Sign in with a code

This is the default way in.

<Steps>
  <Step title="Enter your email">
    On the sign-in page, type your email and click **Continue**.
  </Step>
  <Step title="Enter the code or use the button">
    Open the email from Ryze, type the code into **Verification code** and click **Verify**. Or click **Sign in to Ryze** in the email: it opens **Finish signing in**, where you click **Sign in** — nothing happens until you click it. The code and the button are valid for 1 hour; if you request a new code, use the newest email.
  </Step>
</Steps>

Typed the wrong address? Click **Use a different email**.

## No account for this email yet

If there's no Ryze account under the email you entered, Ryze creates one: you'll see *No account yet, we'll create one. Enter the code sent to…*. Enter the code, then on **One last step** add **Your website** and click **Finish setup**.

<Warning>
Check the address before you enter the code. An email with a typo, or a different address than the one you were invited with, creates a second, empty account — your workspaces won't be there. Click **Use a different email** and sign in with the right one.
</Warning>

If the email belongs to an account on our previous platform, you'll see *Good news — we found your account!* instead — click **Move my account** to bring it over. On a branded (white-label) sign-in page, no account is created: you'll see *No account found with this email.* — ask whoever invited you to check the address.

## Sign in with a password

On the sign-in page, click **Sign in with password**, enter your email and password, and click **Sign in**. To go back to the code, click **Sign in with email code**.

## Forgot your password, or never set one?

The **Forgot password?** link only appears on the password form, so switch to it first.

<Steps>
  <Step title="Open the password form">
    On the sign-in page, click **Sign in with password**, then **Forgot password?**.
  </Step>
  <Step title="Get a reset code">
    Enter your email and click **Send reset code**.
  </Step>
  <Step title="Choose a new password">
    Enter the code from the email and click **Verify**. Then type a new password (at least 8 characters) in **New password** and **Confirm password**, and click **Reset password**.
  </Step>
</Steps>

This is also how you set your first password if you've always signed in with a code.

## Change your password

If you know your current password, open the account menu at the bottom left → **Workspace Settings** → **Profile**, and next to **Password** click **Change**. Enter your current password and the new one twice, then click **Update password**. See [Workspace Settings](/workspaces/settings).

## Trouble signing in

| Message | What to do |
|---|---|
| *This code is wrong or was already used. Request a new one.* | Check the digits, or request a new code and use the newest email. |
| *This code has expired. Request a new one.* | Codes last 1 hour. Request a new one. |
| *Too many wrong codes. Request a new one.* | After 5 wrong tries the code stops working. Request a new one. |
| *A code was just sent. Wait a minute before requesting another one.* | You can request a new code once a minute. |
| *Too many codes were requested for this email today. Try again tomorrow.* | Up to 10 codes per email per day. Use the newest code you already have, or try tomorrow. |
| *Too many attempts. Try again in a minute.* | Wait a minute and try again. |
| *You are signed in as a different account. Sign out first, then open the link again.* | You clicked **Sign in to Ryze** in the email while signed in as someone else. Sign out, then click the button in the email again. |
| *This sign-in link is invalid or has expired. Please request a new one.* | The button is valid for 1 hour. Request a new code on the sign-in page. |

- **No code or reset email?** Check your spam or quarantine folder — some mail hosts, often Microsoft/Outlook domains, hold one-time codes — and mark our emails as not spam. Wait a minute and request the code again. Still nothing? Email [support@get-ryze.ai](mailto:support@get-ryze.ai) from the address you signed up with.
