Open **Workspace Settings → Workspace** to manage how this workspace is set up.

## Workspace basics

<Frame>
  <img src="/images/workspace-settings.png" alt="Workspace settings fields" />
</Frame>

- **Name** — the display name for this workspace
- **Slug** — used in the workspace URL
- **Domain** — the site this workspace covers
- **Location** — the market this workspace targets
- **Language** — the language for generated content

Click **Save changes** when you're done.
