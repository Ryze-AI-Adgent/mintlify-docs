---
title: "Media library"
description: "Upload your product photos and videos once; the agent picks from them for creatives, articles, and ads."
---

Open **Media** in the workspace sidebar. It holds the images and videos you upload plus the product photos the agent saved from your site on earlier runs. Everything here can be picked anywhere in the workspace.

## Upload files

Click **Upload** or drag files onto the page. Each file can be up to 20 MB.

- **Images**: JPG, PNG, WebP, GIF, HEIC, AVIF
- **Videos**: MP4, WebM, MOV

Use **Search files** to find a file. Click a file to open it: the window shows its type, dimensions, size and the date it was added, with a **Download** button. You can rename it or add **alt text** there. A short description of what the photo shows (product, colorway, scene) helps the agent choose the right one and is used for search engines when the image lands in an article.

## How the agent uses it

Before it looks anywhere else, the agent checks Media. A photo you put here is treated as the one you want used: for ad creatives it goes in as the hero image or as the reference that keeps your product identical, and for articles it is the first choice for covers and inline images.

If you want creatives built only from your own footage, say so in the chat: "use only the photos in Media, no generated product images". Attaching a specific file with the **+** button in the composer narrows it to that file.

<Note>
**Brand → Visual** is a different place: it stores your brand colors and fonts, which the agent applies on top of the photos from Media.
</Note>

## Delete a file

Open the file and click **Delete**. The file is removed from storage and from your brand profile if it's used there; creatives and articles that already rendered with it keep their copy. This can't be undone.
